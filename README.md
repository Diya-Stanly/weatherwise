# WeatherWise — Real-Time Weather Dashboard

WeatherWise is a responsive weather dashboard built with HTML, CSS, and JavaScript. It integrates the Open-Meteo API to display current weather conditions and five-day forecasts for searched locations.

## ✨ Features

- 🌍 Search for weather by city
- 📍 Optional geolocation support
- 🌡️ Display current temperature and weather conditions
- 💧 Show humidity and wind speed
- 🌧️ Display precipitation information
- 🌅 Show sunrise and sunset times
- 📅 Provide a five-day weather forecast
- 📱 Responsive dashboard for different screen sizes

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- [Open-Meteo API](https://open-meteo.com/)

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Diya-Stanly/weatherwise.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

If your browser restricts any local-file functionality, run the project using a local development server.

## 🌦️ How It Works

1. Search for a city or use the optional location feature.
2. The application retrieves relevant weather data using the Open-Meteo API.
3. JavaScript processes the response and displays current conditions and forecast information.
4. The dashboard presents the results in a user-friendly interface.

## 🎯 Project Objective

WeatherWise demonstrates frontend development, external API integration, asynchronous JavaScript, and responsive UI design through a practical weather application.
